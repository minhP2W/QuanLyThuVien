# Quản lý thư viện Librio

## Khởi chạy dự án:

### Yêu cầu:

- Đã cài đặt Laragon v6.0 hoặc phiên bản mới nhất

### Cài đặt:

1. Khởi chạy dịch vụ MySQL và Apche trên Laragon
2. Import file backend/database/database.sql
3. Đảm bảo folder dự án đã tạo đã vào trong folder www, sau đó truy cập vào [Local website](http://localhost/Librio)
