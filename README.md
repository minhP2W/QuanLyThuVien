# Quản lý thư viện Librio

## Khởi chạy dự án:

### Yêu cầu:

- Đã cài đặt Laragon v6.0 hoặc phiên bản mới nhất
- Sử dụng Chrome, Cốc Cốc hoặc Microsoft Edge đã cài đặt và áp dụng ngôn ngữ Tiếng Việt để chạy mã nguồn

### Cài đặt:

1. Khởi chạy dịch vụ MySQL và Apche trên Laragon
2. Import file backend/database/database.sql
3. Đảm bảo folder dự án đã tạo đã vào trong folder www, sau đó truy cập vào địa chỉ website:
   1. Quản trị viên/thủ thư: [http://localhost/Librio/index.php?page=dashboard](http://localhost/Librio/index.php?page=dashboard)
   2. Độc giả: [http://localhost/Librio/index.php?page=home](http://localhost/Librio/index.php?page=home)
